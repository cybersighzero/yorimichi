# Adding your own photos

## Product photos
1. Put a photo in `assets/images/products/` with **exactly** the file name below (`.jpg`, `.png` or `.webp`).
2. Refresh. That's it. A missing file just keeps the generated artwork, so you can add them one at a time.

Tips
- Best size: **1000 x 880 px** (landscape-ish, shown cropped to fill the card; keep the subject centred).
- Keep each file under ~300 KB so the shop stays fast.
- The maroon tint on product images is a style choice. For untouched photos, open `css/style.css` and set
  `--pic-tint:0` and `--pic-filter:none` in the `:root` block at the top.
- Adding a new product? Its photo name is its English name in lowercase with dashes, e.g. "Salted Seaweed Chips" -> `salted-seaweed-chips.jpg`.
