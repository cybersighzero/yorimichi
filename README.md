# YORIMICHI — 寄り道 🌸

**Your Little Detour.**

A Japanese-inspired konbini (convenience store) website built around the cosy nostalgia of late-night shopping, warm storefront lights, and little everyday discoveries.

YORIMICHI takes inspiration from Japanese convenience stores and the atmosphere of wandering through quiet neighbourhood streets at night.

## Preview

*A little corner of the internet, open 24/7.*

## Features

- **Product Catalogue** — Browse a collection of fictional konbini products across four categories.
- **Search & Filters** — Find products by name, category, and sorting preferences.
- **Shopping Cart** — Add products, adjust quantities, remove items, and view totals.
- **Wishlist** — Save products for later.
- **Daily Special** — Discover the store's featured product.
- **Random Snack** — Let the store pick something for you.
- **Language Toggle** — Switch between Japanese and English.
- **Responsive Design** — Adapted for desktop and mobile screens.
- **Animations & Interactions** — Small details that bring the storefront to life.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage

No frameworks, backend, or paid APIs. Just frontend code.

## Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/cybersighzero/yorimichi.git
   ```

2. Navigate into the project:

   ```bash
   cd yorimichi
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in VS Code.

#### *Alternatively*, navigate to https://yorimichi-cho.vercel.app if you are extremely lazy :)

## A Little Note

**YORIMICHI (寄り道)** means *a detour* or *taking a little stop along the way* in Japanese.

**YORIMICHI-CHŌ (寄り道町)** combines *yorimichi* (寄り道) with *chō* (町), meaning *town* or *neighbourhood*.

Together, it evokes the idea of a little neighbourhood worth taking a detour for.

Sometimes, the best part of the journey is the little stop you didn't plan.
